# Zyntra
Official website source code for Zyntra Management Consultants — a South African management consulting firm specializing in strategic advisory, governance, compliance, and technology enablement.

## Getting Started

This repository contains a TypeScript + Express project in the `my-project/` directory.

### Prerequisites

- Node.js (v14 or higher)
- npm (comes with Node.js)

### Installation & Setup

1. Navigate to the project directory:
   ```bash
   cd my-project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```

The server will start at `http://localhost:3000`
